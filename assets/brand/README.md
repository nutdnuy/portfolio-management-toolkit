# QuantCorner Approved Logo

Approved on 2026-07-17. The selected direction is the `Research Coordinate Q`: a rounded Q-shaped research frame ending at one green evidence point.

## Master assets

- `quantcorner-mark-dark.svg` — transparent mark for dark surfaces.
- `quantcorner-mark-light.svg` — transparent mark for light surfaces.
- `quantcorner-app-icon.svg` — deep-green avatar and app icon.
- `quantcorner-wordmark-dark.svg` — horizontal presentation lockup.
- `quantcorner-app-icon.png` — 1024px avatar export.
- `quantcorner-wordmark-dark.png` — 2000px horizontal export.
- `favicon-32.png` and `favicon-64.png` — browser favicon exports.
- `approved-reference.png` — the owner-selected concept board.

## Color

- Dark: `#121212`
- Warm off-white: `#F5F3ED`
- Signal green: `#69F0AE`
- Deep editorial green: `#173C2C`
- Accessible light-mode green: `#1E8E63`

## Rules

- Keep clear space equal to at least the green point diameter.
- Preserve the point as a separate circular element.
- Do not add glow, gradients, charts, arrows, coins, or financial symbols.
- Use the symbol-only mark below roughly 180px of horizontal space.
- Convert the wordmark to outlines before final print-vendor handoff.
- The current local web implementation is `lithos-3d-ridge/public/qc-logo-mark.svg`.
