# Portfolio Management Toolkit Notes

<p class="lead">เรียนรู้การจัดการพอร์ต ผ่านคำถาม ตัวอย่าง และการทดลอง</p>

การจัดการพอร์ตเริ่มจากการรู้ว่าเราอยากให้เงินทำหน้าที่อะไร และยอมรับผลลัพธ์แบบไหนได้ หนังสือเล่มนี้จะพาเริ่มจากคำถามเหล่านั้น แล้วค่อยใช้ตัวอย่างและสมการอธิบายว่าแต่ละวิธีทำงานอย่างไร พร้อมเครื่องมือให้ลองเปลี่ยนค่าและดูผลด้วยตัวเอง

เริ่มจาก **[How to Calculate return](returns.html)** เพื่อเริ่มจากเปอร์เซ็นต์ การทบต้น และค่าเฉลี่ย แล้วลอง Python/pandas ทีละขั้น ต่อด้วยการวัดความผันผวน Sharpe ratio, Drawdown และความเสี่ยงปลายหางตามหัวข้อผลตอบแทนและความเสี่ยงของคอร์ส EDHEC มีตัวอย่างสมมติและคำถามพร้อมเฉลย ส่วน Log return อ่านต่อได้หลังเข้าใจพื้นฐาน

ต่อด้วย **[เมื่อผลตอบแทนไม่เป็น Normal](extreme-risk.html)** เพื่อศึกษาความเสี่ยงเมื่อผลตอบแทนไม่เป็น Normal: ดูรูปร่างผลตอบแทน คำนวณ Skewness และ Kurtosis ทดสอบ Normality สร้าง Python module และเปรียบเทียบวิธีวัดความเสี่ยงปลายหางทีละขั้น

<span id="module-2-เร-มสร-างพอร-ต"></span>

## เริ่มสร้างพอร์ต

เริ่มจากการแบ่งเงินระหว่างสินทรัพย์สองตัว แล้วค่อยเพิ่ม covariance matrix และข้อจำกัดในการหาน้ำหนักพอร์ต

1. [เริ่มจัดพอร์ตจากสินทรัพย์สองตัว](portfolio-basics.html) คำนวณน้ำหนัก ผลตอบแทน Covariance และ Correlation จากตัวอย่างเล็ก ๆ
2. [Efficient frontier และการหาน้ำหนักพอร์ต](efficient-frontier.html) อ่าน matrix ตั้งโจทย์ optimization และแยกขอบพอร์ตที่มีประสิทธิภาพออกจากพอร์ตที่สร้างได้ทั้งหมด
3. [MSR, GMV และความคลาดเคลื่อนของค่าประมาณ](portfolio-estimation.html) ผสมสินทรัพย์ปลอดความเสี่ยง เปรียบเทียบวิธีจัดพอร์ต และตรวจการใช้ข้อมูลย้อนหลัง

<span id="module-3-เม-อการกระจายการลงท-นย-งไม-พอ"></span>

## เมื่อการกระจายการลงทุนยังไม่พอ

การถือหลายสินทรัพย์ยังอาจเจอขาดทุนพร้อมกัน เราจะตรวจความสัมพันธ์ของผลตอบแทน แล้วศึกษากฎปรับวงเงินเสี่ยงตามมูลค่าพอร์ต

1. [ข้อจำกัดของ Diversification](diversification-limits.html) สร้างน้ำหนักตามมูลค่าตลาด คำนวณ rolling correlation และตรวจเวลาของข้อมูล
2. [CPPI จากศูนย์](cppi-dynamic-allocation.html) คำนวณ Floor, Cushion และ Multiplier ทีละเดือน รวมถึงเหตุการณ์ที่พอร์ตต่ำกว่า floor
3. [Monte Carlo และการประเมิน CPPI](monte-carlo.html) สร้างหลายเส้นทางด้วย GBM และวัดทั้งโอกาสเกิดเงินขาดกับขนาดเงินที่ขาด

<span id="module-4-ลงท-นให-ส-มพ-นธ-ก-บว-นท-ต-องใช-เง-น"></span>

## ลงทุนให้สัมพันธ์กับวันที่ต้องใช้เงิน

จำนวนเงินและวันจ่ายของเป้าหมายเป็นข้อมูลตั้งต้นของการเลือกสินทรัพย์ เราจะคิดลดภาระ หาสินทรัพย์ที่ช่วยรองรับ และจัดวงเงินสำหรับส่วนที่รับความเสี่ยง

1. [เงินลงทุนกับเป้าหมายที่ต้องจ่าย](asset-liability.html) เริ่มจาก Present Value และ Funding ratio ก่อนแยกหน้าที่ PSP/GHP
2. [พันธบัตร กระแสเงินสด และ Duration](bonds-duration.html) แยก Coupon, Yield, ราคาและผลตอบแทนรวม แล้วลองจับคู่ภาระด้วย Duration
3. [จำลองอัตราดอกเบี้ยและราคา ZCB](interest-rate-models.html) ใช้ CIR โดยแยกความน่าจะเป็นสำหรับสถานการณ์ลงทุนออกจากการคิดราคา
4. [จัดพอร์ตให้เงินพอกับเป้าหมาย](goal-based-allocation.html) เปรียบเทียบ Fixed Mix, Glidepath และการปรับวงเงินตาม Funding ratio พร้อมตรวจ Shortfall

ทั้งสิบหน้ามี Notebook แยกบท พร้อมตัวอย่างที่สร้างขึ้นใหม่ รันได้จากต้นหน้าโดยไม่ต้องเปิดโค้ดของบทอื่น ตัวเลขใหม่ในชุดนี้เป็นข้อมูลสมมติหรือการจำลองที่ระบุพารามิเตอร์และ seed ไม่ใช่ผลจากตลาดจริง

<span id="advanced-module-1-style-factors"></span>

## Advanced · Style & Factors

คอร์สต่อเนื่อง [Advanced Portfolio Construction and Analysis with Python](https://www.coursera.org/learn/advanced-portfolio-construction-python) เริ่มจากการอธิบายผลตอบแทนด้วยปัจจัยร่วม แล้วพาไปสู่การสร้าง benchmark และทดสอบกฎให้น้ำหนัก แบ่งหัวข้อ Style & Factors เป็นสี่บทเพื่อให้มีเวลาฝึกสูตรและ Python ทีละขั้น

1. [Factor Investing และ CAPM จากพื้นฐาน](factor-investing.html) คำนวณ excess return, beta, alpha และ OLS ก่อนแยกค่าประมาณจากข้อสมมติของ CAPM
2. [หลาย Factor และ Fama–French](multifactor-models.html) อ่าน SMB/HML ฝึกแบบจำลองหลายปัจจัย และดูกรณีศึกษา Berkshire จากข้อมูลคอร์สปี 1990–2018
3. [Style Analysis](style-analysis.html) หาส่วนผสม benchmark แยก TE กับ RMSE และติดตามสไตล์ด้วยหน้าต่างย้อนหลัง
4. [จาก Cap Weight สู่ Smart Beta](smart-beta.html) แยกการเลือกหุ้นจากน้ำหนัก ตรวจความกระจุกตัว การซื้อขาย และ backtest ที่ใช้ข้อมูลตามเวลา

ทั้งสี่บทมี Notebook ที่รันได้แยกกัน ตัวอย่างหลักเป็นข้อมูลสมมติ ส่วนกรณีศึกษา Berkshire ระบุไฟล์ ช่วงข้อมูล หน่วย และวิธีคำนวณแยกไว้ พร้อมสคริปต์สำหรับผู้ที่มี ZIP ของคอร์ส

<span id="advanced-module-2-covariance-estimation"></span>

## Advanced · Covariance Estimation

เมื่อรู้แล้วว่า covariance ใช้คำนวณความเสี่ยงพอร์ต บทถัดไปถามว่าควรประมาณมันอย่างไรเมื่อข้อมูลมีจำกัด และความสัมพันธ์ของสินทรัพย์เปลี่ยนไปตามเวลา

1. [ประมาณ Covariance เมื่อข้อมูลมีจำกัด](covariance-estimation.html) เริ่มจากตารางผลตอบแทน ตรวจ rank และอธิบายข้อสมมติของ factor covariance
2. [Shrinkage](covariance-shrinkage.html) ผสม sample covariance กับ constant-correlation target ก่อนเปรียบเทียบพอร์ตด้วย rolling backtest
3. [ความเสี่ยงที่เปลี่ยนตามเวลา](time-varying-risk.html) ตามรอยข้อมูลแต่ละงวดใน rolling window, EWMA และ GARCH พร้อมแยกค่าพยากรณ์ออกจากผลที่เกิดขึ้นจริง

ตัวอย่างและ Notebook ทั้งสามบทใช้ข้อมูลสมมติที่ระบุวิธีสร้างไว้ คำนวณตามได้โดยไม่ต้องดาวน์โหลดข้อมูลตลาด

<span id="advanced-module-3-expected-returns"></span>

## Advanced · Expected Returns

Covariance เป็นเพียงส่วนหนึ่งของข้อมูลเข้าของ optimizer บทเรียนชุดนี้พิจารณาว่าควรเชื่อค่าเฉลี่ยผลตอบแทนย้อนหลังแค่ไหน และจะรวมสมมติฐานกับมุมมองเพิ่มเติมอย่างไร

1. [Expected Return: ค่าเฉลี่ยที่เรายังไม่รู้](expected-return-estimation.html) แยก SD กับ Standard Error ทดลอง mean shrinkage และตรวจข้อสมมติที่ใช้เปลี่ยน factor loadings เป็นค่าคาดหวัง
2. [Implied Returns และ Views](implied-returns-views.html) เริ่มจากน้ำหนักพอร์ต สร้างผลตอบแทนที่สอดคล้องกับแบบจำลอง แล้วเขียนมุมมองแบบระบุสินทรัพย์และแบบเปรียบเทียบ
3. [Black–Litterman](black-litterman.html) ผสม prior กับ views ตามความไม่แน่นอน แยกความเสี่ยงของผลตอบแทนออกจากความไม่แน่นอนของค่าเฉลี่ย แล้วหาน้ำหนักภายใต้โจทย์ที่ระบุไว้

ทั้งสามบทมี Notebook ที่เริ่มรันแยกกันได้ ตัวอย่าง views เป็นสมมติฐานสำหรับฝึกคำนวณ ไม่มีการคาดการณ์สินทรัพย์จริง

<span id="advanced-module-4-portfolio-optimization-in-practice"></span>

## Advanced · Portfolio Optimization in Practice

เมื่อค่าผลตอบแทนและความเสี่ยงยังไม่แน่นอน เราจะเลือกกฎจัดพอร์ตอย่างไร บทเรียนชุดนี้แยกการกระจายเงินออกจากการกระจายความเสี่ยง แล้วทดสอบกฎเหล่านั้นบนข้อมูลและช่วงเวลาเดียวกัน

1. [Diversification: กระจายเงินด้วยวิธีใด](diversification-methods.html) เทียบ Equal Weight, Market Cap, GMV และ Maximum Diversification พร้อมวัดการกระจุกตัวของเงินด้วย ENC
2. [Risk Contribution](risk-contributions.html) คำนวณว่าสินทรัพย์แต่ละตัวมีส่วนต่อความผันผวนของพอร์ตเท่าไร และอ่านส่วนแบ่งที่ติดลบอย่างไร
3. [Risk Parity](risk-parity.html) เริ่มจาก Inverse Volatility แล้วแก้โจทย์ Equal Risk Contribution และงบความเสี่ยงที่กำหนดไว้
4. [ทดสอบ Diversification](diversification-backtest.html) สร้างการทดสอบย้อนหลังที่ใช้เฉพาะข้อมูลก่อนตัดสินใจ ติดตามน้ำหนักที่เปลี่ยน และหักต้นทุนจากเงินลงทุนอย่างสอดคล้องกัน

ตัวอย่างสี่สินทรัพย์และข้อมูลทดสอบเป็นข้อมูลสมมติที่สร้างเพื่อสอนวิธีคำนวณ ผลเปรียบเทียบไม่ได้ยืนยันว่าวิธีใดชนะตลาด

## บทอ่านประกอบ

อ่าน **[ความเสี่ยงในการลงทุน](risk.html)** เพื่อทำความเข้าใจว่าความเสี่ยงหมายถึงอะไร แนวคิดนี้พัฒนามาอย่างไร และแต่ละทฤษฎีตอบคำถามใด ก่อนเปรียบเทียบ Volatility, Downside, Drawdown, VaR และ Expected Shortfall พร้อมทดลองเปลี่ยนลำดับผลตอบแทน ความเสียหายปลายหาง และน้ำหนักข้อมูลใน EWMA

อีกบทหนึ่งคือ **[Portfolio Insurance Strategies: Friend or Foe?](portfolio-insurance.html)** เราอยากให้พอร์ตเติบโต แต่ก็อยากจำกัดเงินที่อาจเสียไปด้วย บทนี้จะพาจากการซื้อ Put เพื่อป้องกันสินทรัพย์หนึ่งหน่วย ไปจนถึงกฎจัดพอร์ตอย่าง CPPI และ TIPP แล้วกลับมาดูว่าเราจ่ายอะไรไปบ้างเพื่อแลกกับความคุ้มครอง และผู้ลงทุนให้คุณค่ากับมันอย่างไร

บท Portfolio Insurance ใช้วิทยานิพนธ์ของ **Paulo José Martins Jorge da Silva (2018)** เป็นจุดตั้งต้น แล้วเรียบเรียงคำอธิบายและเพิ่มตัวอย่างให้คำนวณตามได้ ส่วนไหนเป็นข้อค้นพบจากงานวิจัยจะมีที่มาและเลขหน้ากำกับไว้ เพื่อให้อ่านต่อและตรวจกลับได้

## อ่านหนังสือเล่มนี้อย่างไร

เปิดบทเรียนจากแถบด้านข้างแล้วอ่านต่อได้ตามลำดับ ถ้าเจอคำที่ยังไม่คุ้น แวะดู[หน้าคำศัพท์](glossary.html) แล้วกดกลับมายังตัวอย่างได้ ระหว่างอ่านจะมีเครื่องมือให้ลองปรับค่า แนะนำให้เปลี่ยนทีละตัว แล้วดูว่าผลที่ออกมาตรงกับเหตุผลที่เราคิดไว้หรือไม่

สำหรับบทเรียนตั้งแต่การสร้างพอร์ตไปจนถึงชุด Advanced กด “ดาวน์โหลด Notebook” จากสารบัญของหน้าที่กำลังอ่าน เปิดไฟล์ `.ipynb` ใน Jupyter Notebook หรือ JupyterLab แล้วรันจากช่องแรกลงมา หากอยากเริ่มใหม่ให้ Restart Kernel แล้ว Run All เพื่อไม่ให้ค่าจากการทดลองก่อนหน้าค้างอยู่ Python ของชุดนี้ใช้ NumPy, pandas และ SciPy; หากยังไม่มีแพ็กเกจ ให้รัน `%pip install numpy pandas scipy` ในช่องของ Jupyter ก่อนแล้วเริ่ม kernel ใหม่ คำสั่งที่ขึ้นต้นด้วย `%` ใช้ใน Jupyter ไม่ใช่ไฟล์ Python ปกติ

Notebook มีผลรันบันทึกไว้ให้เทียบ แต่ผู้อ่านควรรันใหม่และลองเปลี่ยนค่าทีละตัวด้วย บท [Portfolio Insurance มี Notebook ของตัวเอง](notebooks/portfolio-insurance.ipynb) แยกจากชุดบทเรียนข้างต้น
