# คำศัพท์ที่ใช้ใน Toolkit

นิยามต่อไปนี้เรียบเรียงใหม่สำหรับบทเรียน Portfolio Insurance เลขหน้าที่กำกับหมายถึงวิทยานิพนธ์ da Silva (2018) โดย **หน้า PDF = หน้าพิมพ์ + 27** สำหรับเนื้อหาหลัก [ข้อมูลแหล่งต้นฉบับ](research.html#source)

<a id="portfolio-insurance"></a>

## Portfolio Insurance · กลยุทธ์ป้องกันพอร์ต

กลุ่มกลยุทธ์ที่มุ่งจำกัดการลดลงของมูลค่าพอร์ต พร้อมเหลือโอกาสรับการเติบโต อาจใช้ Option หรือกฎปรับสินทรัพย์ คำว่า Insurance ในชื่อไม่ได้หมายความว่าทุกแบบมีบริษัทประกันหรือคู่สัญญารับประกันผลลัพธ์

[กลับไปบทเรียน](portfolio-insurance.html) · แหล่งแนวคิด: พิมพ์ น. 4–16 / PDF 31–43

<a id="floor"></a>

## Floor · ระดับมูลค่าที่มุ่งป้องกัน

เป้าหมายขั้นต่ำของมูลค่าพอร์ต ต้องระบุจำนวนเงินและเวลา Floor เมื่อครบกำหนด $F_T$ อาจต่างจากมูลค่าปัจจุบัน $F_t$ ที่ใช้ในกฎปรับพอร์ต

[ดู Floor และ Cushion](portfolio-insurance.html#floor-and-cushion) · แหล่งแนวคิด: พิมพ์ น. 9, 13–15 / PDF 36, 40–42

<a id="cushion"></a>

## Cushion · ส่วนต่างเหนือ Floor

ผลต่าง $C_t=V_t-F_t$ ระหว่างมูลค่าพอร์ตกับ Floor ณ เวลาเดียวกัน วัดเป็นหน่วยเงินเดียวกับพอร์ต ใน CPPI เป็นฐานที่นำไปคูณ Multiplier เพื่อกำหนดเงินลงทุนเสี่ยง

[ดูตัวอย่าง CPPI](portfolio-insurance.html#cppi-example) · แหล่งแนวคิด: พิมพ์ น. 13–15 / PDF 40–42

<a id="multiplier"></a>

## Multiplier · ตัวคูณ Cushion

พารามิเตอร์ $m$ ที่แปลง Cushion เป็นเงินลงทุนในสินทรัพย์เสี่ยงก่อนใช้ข้อจำกัดอื่น ไม่มีหน่วย $m=3$ หมายถึงสามเท่าของ Cushion ไม่ใช่สามเท่าของมูลค่าพอร์ต รุ่นไม่กู้เงินจะจำกัดเงินลงทุนเสี่ยงไม่ให้เกินมูลค่าพอร์ต

[ดูกฎ CPPI](portfolio-insurance.html#cppi-example) · แหล่งแนวคิด: พิมพ์ น. 14–15, 52–53 / PDF 41–42, 79–80

<a id="rebalancing"></a>

## Rebalancing · การปรับสัดส่วนพอร์ต

ซื้อขายเพื่อให้จำนวนเงินหรือสัดส่วนสินทรัพย์ตรงกับกฎหลังราคาและมูลค่าพอร์ตเปลี่ยน การกำหนดเป้าหมายต่อเนื่องในสูตรกับการซื้อขายจริงเป็นรอบให้ผลต่างกันได้

[ดูความเสี่ยงระหว่างรอบ](portfolio-insurance.html#gap-risk) · แหล่งแนวคิด: พิมพ์ น. 14–16, 52–53 / PDF 41–43, 79–80

<a id="gap-risk"></a>

## Gap risk · ความเสี่ยงจากการกระโดดข้ามเกณฑ์

ความเสี่ยงที่ราคาหรือมูลค่าพอร์ตเคลื่อนที่ผ่านระดับป้องกันก่อนจะลดการถือสินทรัพย์เสี่ยงได้ การขายหลังจากหลุดเกณฑ์ไม่ทำให้พอร์ตกลับไปมีมูลค่าเท่าเกณฑ์โดยอัตโนมัติ

[ดูตัวอย่างพอร์ต 100 เหลือ 76](portfolio-insurance.html#gap-risk) · แหล่งแนวคิด: พิมพ์ น. 32–33 / PDF 59–60

<a id="cash-lock"></a>

## Cash lock · พอร์ตติดอยู่ในสินทรัพย์ปลอดความเสี่ยง

ภาวะที่กฎป้องกันทำให้เงินลงทุนในสินทรัพย์เสี่ยงลดเหลือศูนย์ และกลยุทธ์ไม่กลับเข้าตลาดในช่วงที่เหลือ จึงอาจไม่มีส่วนร่วมกับการฟื้นตัวของตลาด

[ดู Gap risk และ Cash lock](portfolio-insurance.html#gap-risk) · แหล่งแนวคิด: พิมพ์ น. 14 / PDF 41

<a id="obpi"></a>

## OBPI · Option Based Portfolio Insurance

การจัดพอร์ตให้มีลักษณะการป้องกันด้วย Option เช่น สินทรัพย์เสี่ยงบวก Put หรือ Bond บวก Call การซื้อ Option จริงกับการปรับสินทรัพย์เพื่อเลียนแบบ Option มีเงื่อนไขดำเนินงานต่างกัน

[ดู Payoff กับงบซื้อการป้องกัน](portfolio-insurance.html#option-budget) · แหล่งแนวคิด: พิมพ์ น. 10–13 / PDF 37–40

<a id="cppi"></a>

## CPPI · Constant Proportion Portfolio Insurance

กฎจัดสรรเงินลงทุนเสี่ยงตามตัวคูณคงที่ของ Cushion เมื่อ Cushion เล็กลง เงินลงทุนเสี่ยงตามกฎจะลดลง รุ่นที่ใช้ข้อจำกัดไม่กู้และไม่ขายชอร์ตจะจำกัดเงินลงทุนเสี่ยงให้อยู่ระหว่างศูนย์กับมูลค่าพอร์ต

[ดูตัวอย่างทีละขั้น](portfolio-insurance.html#cppi-example) · แหล่งแนวคิด: พิมพ์ น. 13–15, 52–53 / PDF 40–42, 79–80

<a id="tipp"></a>

## TIPP · Time Invariant Portfolio Protection

แนวทางต่อยอดจาก CPPI ที่ยก Floor ตามเงื่อนไขเมื่อมูลค่าพอร์ตเพิ่มขึ้น เพื่อเก็บการเติบโตบางส่วนไว้ในเป้าหมายป้องกัน การกำหนดว่าจะยก Floor อย่างไรต้องระบุให้ชัดก่อนเปรียบเทียบผล

[ดูตารางกลยุทธ์](portfolio-insurance.html#strategies) · แหล่งแนวคิด: พิมพ์ น. 15–16 / PDF 42–43

<a id="payoff"></a>

## Payoff · มูลค่าที่ได้ตามโครงสร้างเมื่อครบกำหนด

มูลค่าจ่ายจากสินทรัพย์หรือสัญญาตามผลลัพธ์ปลายทาง ยังไม่เท่ากับกำไรจากเงินลงทุนตั้งต้น เช่น Payoff ของ Put คือ $\max(K-S_T,0)$ แต่ผู้ซื้อจ่าย Premium เพื่อได้สิทธินี้

[ดูตัวอย่าง Protective put](portfolio-insurance.html#option-budget) · แหล่งแนวคิด: พิมพ์ น. 10–13 / PDF 37–40

<a id="drawdown"></a>

## Drawdown · การลดลงจากจุดสูงสุดก่อนหน้า

ที่เวลา $t$ ถ้าจุดสูงสุดของมูลค่าพอร์ตจนถึงเวลานั้นคือ $H_t$ ขนาด Drawdown คือ $1-V_t/H_t$ ส่วน Maximum drawdown คือค่าสูงสุดของขนาดดังกล่าวตลอดช่วงที่วัด การลดจากจุดสูงสุดต่างจากการขาดทุนเทียบเงินตั้งต้นและการหลุด Floor

[ดูกรอบเปรียบเทียบกลยุทธ์](portfolio-insurance.html#how-to-compare) · นิยามประกอบเครื่องมือของเว็บไซต์

<a id="expected-utility"></a>

## Expected utility · อรรถประโยชน์คาดหมาย

ค่าเฉลี่ยของ Utility ที่ได้จากผลลัพธ์หลายแบบ ถ้า $W_T$ เป็นความมั่งคั่งปลายทาง เกณฑ์คือ $\mathbb{E}[U(W_T)]$ รูปร่างของ $U$ สะท้อนว่าผู้ลงทุนให้คุณค่ากับความมั่งคั่งและความเสี่ยงอย่างไร

[อ่าน EUT กับ CPT](research.html#eut-cpt) · แหล่งแนวคิด: พิมพ์ น. 43–47, 86–89 / PDF 70–74, 113–116

<a id="loss-aversion"></a>

## Loss aversion · ความไวต่อการสูญเสีย

การให้ผลกระทบด้านลบแก่การขาดทุนมากกว่าผลกระทบด้านบวกจากกำไรขนาดเท่ากัน เมื่อวัดจากจุดอ้างอิงเดียวกัน เป็นคนละแนวคิดกับการไม่ชอบความผันผวนโดยรวม

[อ่าน CPT](research.html#eut-cpt) · แหล่งแนวคิด: พิมพ์ น. 81–84 / PDF 108–111

<a id="reference-point"></a>

## Reference point · จุดอ้างอิง

ฐานที่ใช้ตัดสินว่าผลลัพธ์หนึ่งเป็นกำไรหรือขาดทุน ในตาราง CPT ของวิทยานิพนธ์ใช้เงินตั้งต้น 100 หรือผลตอบแทน 0% การปรับ Floor ไม่ได้หมายความว่าจุดอ้างอิงต้องเปลี่ยนตาม

[อ่านวิธีประเมิน CPT](research.html#eut-cpt) · แหล่งแนวคิด: พิมพ์ น. 84, 90, 95 / PDF 111, 117, 122

<a id="cpt"></a>

## CPT · Cumulative Prospect Theory

กรอบอธิบายการตัดสินใจที่ประเมินกำไรและขาดทุนเทียบจุดอ้างอิง ร่วมกับน้ำหนักการตัดสินใจที่คำนวณจากความน่าจะเป็นสะสม คะแนน CPT จึงมีความหมายตาม Value function และน้ำหนักที่เลือก ไม่ใช่ผลตอบแทนจากการลงทุน

[อ่านผลวิจัย](research.html#findings) · แหล่งแนวคิด: พิมพ์ น. 83–91 / PDF 110–118

<a id="gbm"></a>

## GBM · Geometric Brownian Motion

แบบจำลองการเคลื่อนที่ของราคาที่รักษาระดับราคาให้เป็นบวก ภายใต้ Drift และ Volatility คงที่ Log return ของช่วงเวลาที่กำหนดเป็น Normal และราคาปลายช่วงเป็น Lognormal ไม่ได้รวมการกระโดดของราคาแบบฉับพลันไว้ในกระบวนการต่อเนื่องพื้นฐาน

[ดูวิธีจำลองในงาน](research.html#study-design) · แหล่งแนวคิด: พิมพ์ น. 48–49, 85 / PDF 75–76, 112

<a id="sampling-error"></a>

## Sampling error · ความคลาดเคลื่อนจากการสุ่ม

ความต่างของค่าประมาณที่เกิดจากใช้ตัวอย่างสุ่มจำนวนจำกัด แม้ใช้แบบจำลองและพารามิเตอร์เดิม การเพิ่มจำนวนเส้นทางช่วยลดส่วนนี้ได้ แต่ไม่ได้แก้การเลือกแบบจำลองที่ไม่ตรงกับตลาด

[อ่านข้อจำกัดของผลจำลอง](research.html#limitations) · คำอธิบายประกอบการอ่านงานที่เว็บไซต์เพิ่ม

<a id="model-risk"></a>

## Model risk · ความเสี่ยงจากแบบจำลอง

ความเสี่ยงที่สมมติฐาน โครงสร้าง พารามิเตอร์ หรือการนำแบบจำลองไปใช้ไม่เหมาะกับสิ่งที่ต้องการประเมิน เช่น ใช้แบบราคาต่อเนื่องเพื่อสรุปว่ากฎซื้อขายรับมือการกระโดดของราคาได้เสมอ

[อ่านข้อจำกัดของผลจำลอง](research.html#limitations) · คำอธิบายประกอบการอ่านงานที่เว็บไซต์เพิ่ม
