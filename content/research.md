# งานวิจัยบอกอะไร และยังบอกอะไรไม่ได้

Portfolio Insurance อาจดึงดูดคนที่อยากรักษาเงินลงทุนไว้พร้อมรับโอกาสเติบโต แต่ **ความน่าดึงดูดใจ ผลตอบแทนที่สูงกว่า และความสามารถรักษา Floor เป็นคนละคำถาม** วิทยานิพนธ์ฉบับนี้ช่วยให้แยกสามเรื่องนี้ออกจากกัน

หน้านี้สรุปหลักฐานจากต้นฉบับ โดยเรียบเรียงภาษาไทยใหม่ ผลของงานปี 2018 และแบบจำลองในงานต้องอ่านภายใต้บริบทของงานนั้น ห้องทดลองในเว็บไซต์เป็นสื่อการสอนที่สร้างขึ้นเพิ่มเติม ไม่ใช่การทำซ้ำผลวิจัยครบชุด

## งานจำลองอะไร

งานทดลองในบท 4–5 สร้างเส้นทางราคาด้วย [Geometric Brownian Motion](glossary.html#gbm) แล้วนำแต่ละกลยุทธ์ไปทำงานบนเส้นทางจำลอง กรอบนี้ให้ **Log return เป็น Normal และระดับราคาเป็น Lognormal** ภายใต้พารามิเตอร์คงที่

| องค์ประกอบ | ที่ระบุในวิทยานิพนธ์ |
|---|---|
| ระยะเวลาลงทุน | 1 ปี, 252 วันซื้อขาย |
| จำนวนเส้นทาง | 100,000 เส้นทางต่อสถานการณ์ |
| สถานการณ์ | 9 คู่ของอัตราผลตอบแทนที่ตั้งไว้ 5%, 10%, 15% และความผันผวน 10%, 20%, 30% ต่อปี |
| อัตราปลอดความเสี่ยงฐาน | 5% ต่อปี |
| กลยุทธ์ป้องกัน | SLPI, Synthetic OBPI, CPPI ที่ $m=1$ และ $m=3$, TIPP |
| ตัวเปรียบเทียบ | ถือสินทรัพย์เสี่ยง, พอร์ตเริ่มต้นเสี่ยง/ปลอดความเสี่ยง 50:50 แบบ Passive, สินทรัพย์ปลอดความเสี่ยง |
| ข้อจำกัด CPPI | เงินลงทุนเสี่ยงถูกจำกัดให้อยู่ระหว่างศูนย์กับมูลค่าพอร์ต |
| ต้นทุนที่ไม่รวม | ภาษี ส่วนต่างราคาซื้อขาย และค่าธรรมเนียมซื้อขาย |

ข้อมูลในตารางมาจากพิมพ์ น. 48–53 / PDF 75–80 และพิมพ์ น. 85–86 / PDF 112–113 ตัวเลขเหล่านี้เป็น **ค่าตั้งต้นของการทดลอง ไม่ใช่ประมาณการตลาดปัจจุบัน** คำว่า 50:50 ในงานนี้หมายถึงการจัดเงินเริ่มต้นเท่ากันและถือแบบ Passive จึงไม่ควรตีความว่าเป็นกฎปรับกลับเป็น 50:50 ทุกวัน

Floor หลักอยู่ที่ 100% ของเงินตั้งต้น และงานทดสอบความไวเมื่อปรับเป็น 80% รวมทั้งเปลี่ยนพารามิเตอร์ CPT และอัตราปลอดความเสี่ยงเป็น 3.5% กับ 6.5% [พิมพ์ น. 91–98 / PDF 118–125](#source)

## EUT กับ CPT มองผลลัพธ์ต่างกันอย่างไร

### Expected Utility Theory · EUT

EUT ประเมินการกระจายของความมั่งคั่งปลายทางผ่านฟังก์ชันอรรถประโยชน์ เป้าหมายคือค่าสูงสุดของ $\mathbb{E}[U(W_T)]$ ไม่ใช่ค่าสูงสุดของ $\mathbb{E}[W_T]$ เสมอไป ทั้งสองจะให้เกณฑ์เดียวกันในกรณี Utility เป็นเส้นตรง

บท 5 ใช้สามกรณีเพื่อเปรียบเทียบ: $U(W)=\ln W$ สำหรับผู้หลีกเลี่ยงความเสี่ยง, $U(W)=W$ สำหรับผู้เป็นกลางต่อความเสี่ยง และ $U(W)=W^2$ สำหรับผู้ชอบความเสี่ยงบนช่วงความมั่งคั่งบวก ในสถานการณ์และ Utility ที่เลือก ผลไม่ได้สนับสนุนอย่างชัดเจนว่า Portfolio Insurance เป็นตัวเลือกอันดับแรกโดยทั่วไป จึงยังอธิบายความนิยมของผลิตภัณฑ์ได้ไม่ดี [พิมพ์ น. 86–89 / PDF 113–116, ตาราง 5.1]

**ขอบเขตการอ่าน:** งานนี้ไม่ใช่บทพิสูจน์ว่า Portfolio Insurance ไม่มีประโยชน์สำหรับผู้ใช้ EUT ทุกคน บท 4 เองพบว่าความผันผวน ผลตอบแทนที่ตั้งไว้ และระดับ Risk aversion สามารถเปลี่ยนการเลือกกลยุทธ์ได้ [พิมพ์ น. 76–78 / PDF 103–105]

### Cumulative Prospect Theory · CPT

CPT ประเมินผลเป็นกำไรหรือขาดทุน **เทียบกับจุดอ้างอิง** พร้อมให้ความไวต่อการสูญเสียและให้น้ำหนักการตัดสินใจแก่ความน่าจะเป็นแบบไม่เป็นเส้นตรง งานนี้ใช้เงินตั้งต้น 100 เป็นจุดอ้างอิงในการคำนวณตารางผล ไม่ใช่ Floor ที่ขยับลงเป็น 80 ในการทดสอบความไว [พิมพ์ น. 84–85, 90, 95 / PDF 111–112, 117, 122]

รูปแบบ Value function ที่ใช้คือ

$$
v(x)=\begin{cases}
x^\alpha & x\geq0\\
-\lambda(-x)^\beta & x<0
\end{cases}
$$

โดย $x$ คือผลต่างความมั่งคั่งจากจุดอ้างอิง $\alpha,\beta$ กำกับความไวต่อขนาดกำไรและขาดทุน ส่วน $\lambda$ กำกับความไวต่อขาดทุนเทียบกับกำไร งานใช้ค่าฐาน $\alpha=\beta=0.88$, $\lambda=2.25$ และพารามิเตอร์ถ่วงน้ำหนักความน่าจะเป็นแยกฝั่งกำไร/ขาดทุนจากวรรณกรรมที่อ้างไว้ [พิมพ์ น. 84 / PDF 111]

การเปลี่ยน Value function เพียงอย่างเดียวยังไม่เท่ากับ CPT ครบรูปแบบ CPT ต้องเรียงผลลัพธ์และคำนวณน้ำหนักจากความน่าจะเป็นสะสมด้วย น้ำหนักการตัดสินใจเหล่านี้ไม่ควรถูกเรียกว่า “โอกาสเกิดจริง” [พิมพ์ น. 83–84 / PDF 110–111]

## ผลที่น่าสนใจ: เปลี่ยนเกณฑ์มอง ผลจัดอันดับก็เปลี่ยน

เมื่อใช้ CPT งานพบว่า Portfolio Insurance หลายกรณีมีคุณค่าที่ผู้ลงทุนตามแบบจำลองรับรู้สูงขึ้น โดยเฉพาะกลยุทธ์ง่ายอย่าง SLPI ในการทดลอง Floor 100% แต่ผลขึ้นอยู่กับสถานการณ์

ตัวอย่างที่อ่านจาก **ตาราง 5.2 Panel C**:

| สถานการณ์จำลอง | SLPI | CPPI $m=3$ | ถือสินทรัพย์เสี่ยง |
|---|---:|---:|---:|
| ผลตอบแทนที่ตั้งไว้ 15%, ความผันผวน 30% | 17.04 | 11.61 | 6.96 |
| ผลตอบแทนที่ตั้งไว้ 15%, ความผันผวน 10% | 15.50 | 6.58 | 15.83 |

**ทุกตัวเลขในตารางเป็นคะแนน Cumulative prospect value ตามสเกลของงาน ไม่ใช่ผลตอบแทนร้อยละหรือจำนวนเงิน** ที่ Floor 100% ผลตารางนี้ให้ SLPI มีคะแนนสูงสุดใน 8 จาก 9 สถานการณ์ ข้อยกเว้นคือผลตอบแทนที่ตั้งไว้สูงและความผันผวนต่ำ ซึ่งการถือสินทรัพย์เสี่ยงได้คะแนนสูงกว่า [พิมพ์ น. 90–91 / PDF 117–118; ตรวจเทียบภาพหน้าตารางต้นฉบับ]

เมื่อปรับ Floor ลงเป็น 80% การจัดอันดับเปลี่ยนไป และ CPPI มีบทบาทมากขึ้นในหลายสถานการณ์ ผู้เขียนจึงสรุปว่า CPT **อาจช่วยอธิบายความนิยม** ของ Portfolio Insurance ได้ และย้ำว่าการเลือกแบบใดขึ้นกับเงื่อนไขตลาดและการออกแบบกลยุทธ์ [ตาราง 5.4 และข้อสรุป พิมพ์ น. 95, 97–98 / PDF 122, 124–125]

ข้อสรุปที่นำไปใช้กับการเรียนรู้ได้คือ การถามว่า “ชอบการคุ้มครองเพียงใด” และ “ยอมแลกผลตอบแทนเท่าไร” ต้องเปิดเผยเกณฑ์ประเมินก่อน ความนิยมภายใต้แบบจำลองพฤติกรรมไม่ได้ยืนยันว่ากลยุทธ์นั้นสร้างผลตอบแทนสูงสุดหรือเหมาะกับทุกคน

<a id="limitations"></a>

## ข้อจำกัดที่เปลี่ยนความหมายของผล

- **เป็นหลักฐานภายใต้แบบจำลอง:** ผลหลักมาจากเส้นทาง GBM และพารามิเตอร์ที่ผู้วิจัยตั้งไว้ ไม่ใช่การติดตามพอร์ตลงทุนจริงที่ดำเนินการครบเงื่อนไขทุกกลยุทธ์
- **ระยะสั้นเมื่อเทียบกับบางเป้าหมาย:** งานใช้หนึ่งปี ผู้เขียนระบุว่าควรศึกษาระยะยาวเพิ่มเติม โดยเฉพาะ CPPI/TIPP และเป้าหมายแบบกองทุนเกษียณ [พิมพ์ น. 49 เชิงอรรถ 7 / PDF 76]
- **ต้นทุนยังไม่ครบ:** ไม่รวมภาษี ค่าซื้อขายและ Bid–ask spread ซึ่งอาจกระทบกลยุทธ์ที่ปรับพอร์ตบ่อย [พิมพ์ น. 49 / PDF 76]
- **พารามิเตอร์ความชอบไม่ได้ประมาณจากเจ้าของพอร์ตแต่ละคน:** ค่าฐาน CPT มาจากวรรณกรรม ไม่ได้พิสูจน์ว่าผู้อ่านทุกคนมี Loss aversion เท่ากัน [พิมพ์ น. 84 / PDF 111]
- **ข้อสรุปเปลี่ยนตามสัญญาและกฎ:** Floor, Multiplier, การยอมให้กู้ และการใช้ Option จริงหรือสังเคราะห์มีผลต่อสิ่งที่เปรียบเทียบ [พิมพ์ น. 50–53, 91–98 / PDF 77–80, 118–125]

การเพิ่มจำนวนเส้นทางช่วยลดความคลาดเคลื่อนจากการสุ่ม แต่ไม่ทำให้สมมติฐานตลาดสมจริงขึ้นโดยอัตโนมัติ ข้อนี้เป็นหลักการอ่านแบบจำลองที่เว็บไซต์เพิ่มเพื่อแยก [Sampling error](glossary.html#sampling-error) ออกจาก [Model risk](glossary.html#model-risk)

## Robo-advisors: Risk profile เดียวกันไม่ได้แปลว่าได้พอร์ตเดียวกัน

บท 6 ศึกษาแพลตฟอร์ม **5 ราย** ในบริบทที่เข้าถึงได้ขณะจัดทำวิทยานิพนธ์ โดยสร้างผู้ลงทุนแบบ Conservative, Moderate และ Aggressive แล้วตรวจคำถาม การจัดสินทรัพย์ และลักษณะความเสี่ยงที่ได้ ผู้เขียนแบ่งองค์ประกอบคำถามเป็นความคาดหวัง ความสามารถรับความเสี่ยง ความชอบความเสี่ยง และความตระหนักถึงความเสี่ยง [พิมพ์ น. 108–110 / PDF 135–137]

งานพบว่าพอร์ตที่ได้จากโปรไฟล์ลักษณะเดียวกันมีการจัดสรรและรูปแบบ Risk–return ต่างกันระหว่างแพลตฟอร์ม จึงตั้งข้อกังวลว่าความเข้าใจของผู้ลงทุนกับสิ่งที่พอร์ตส่งมอบอาจไม่ตรงกัน [พิมพ์ น. 114–117, 120–121 / PDF 141–144, 147–148]

แต่การประเมินนี้มีข้อจำกัดที่ต้องอ่านพร้อมผล:

1. การเลือกแพลตฟอร์มขึ้นกับการเข้าถึงและข้อมูลที่เปิดเผย จึงเป็นตัวอย่างขนาดเล็ก [พิมพ์ น. 108 / PDF 135]
2. เมื่อไม่มีสินทรัพย์หรือประวัติราคาตรงตัว งานใช้ ETF หรือดัชนีที่ใกล้เคียงมาทดแทน พร้อมนำข้อมูลย้อนหลังมาวิเคราะห์ ไม่ใช่ผลดำเนินการจริงของบัญชีลูกค้าทุกราย [พิมพ์ น. 111–112 / PDF 138–139]
3. การแยกความเสี่ยงสมมติให้แต่ละดัชนีมีตัวขับเคลื่อนความเสี่ยงหลักหนึ่งประเภท และให้ความสัมพันธ์ระหว่างประเภทความเสี่ยงเป็นศูนย์ [พิมพ์ น. 113 / PDF 140]

จึงควรอ่านส่วนนี้เป็น **กรณีศึกษาว่าการแปลงแบบสอบถามเป็นพอร์ตต้องตรวจอะไร** ไม่ใช่การจัดอันดับบริการ Robo-advisor ในปัจจุบัน และความแตกต่างระหว่างพอร์ตเพียงอย่างเดียวยังไม่พิสูจน์ว่าทุกพอร์ตไม่เหมาะสม

## จากงานวิจัยสู่ Toolkit นี้

เว็บไซต์เลือกใช้วิทยานิพนธ์เป็นจุดเริ่มต้นของโมดูล Portfolio Insurance: เรียนรู้กลไก ทดลองผลของกฎ และอ่านข้อจำกัด หลักฐานวิทยานิพนธ์จะระบุเลขหน้า ส่วนสถานการณ์ที่สร้างใหม่จะแสดงว่าเป็นตัวอย่างหรือการจำลองเพื่อการเรียนรู้

เป้าหมายของเครื่องมือคือให้ผู้เรียนอธิบายได้ว่า **เกิดอะไรขึ้นกับเงินในพอร์ต เมื่อ Floor, Cushion และตลาดเปลี่ยน** ก่อนนำผลไปเปรียบเทียบกับเป้าหมายการลงทุนที่มีเงื่อนไขจริง
